# 模型输入包和输出

初版不实现这里。API 和本地小模型以后都按这一份约定，配置里只启用一个。

## 输入

模型只收到这四样，看不到整本书，也不能自己再去书里抽段落：

| 字段 | 从哪来 |
| --- | --- |
| 筛选单 | cli 整理出的主问题、领域、已有事实、容量、想要的结果 |
| 筛中段落 | filter 留下的段，每段有路径、章节标题、信息种类、正文 |
| 会话记录 | `data/sessions/`。复查阶段之前为空 |
| 形势摘要 | `data/context/` 里当前这一份。要有标题、日期、来源、适用范围，并且未过期 |

没有来源或没有日期的摘要不读。筛中不足两段时不调用模型。

## 输出

原来的四块（主线、规划、建议、下次开口可以带什么），再加一块形势对照。形势对照的信息种类固定写「形势判断」。

四块里的路径必须都在筛中清单内。出现清单外路径时，整段作废，退回初版的填段回复，不把这次模型输出交给用户。

密钥放在环境变量，不进 `planner/`，不进 `data/sessions/`。本地模型的权重放在项目外，不提交进仓库。
